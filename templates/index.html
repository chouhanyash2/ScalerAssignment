How it works
01
Detection — spaCy's NER model finds names, orgs, and locations. Custom regex patterns handle structured data like emails, phone numbers, Indian PAN/Aadhaar, CINs, and GSTINs.
02
Replacement — Every detected span is replaced with a realistic fake generated by Faker (locale-aware). The same original text always maps to the same fake, so the document stays coherent.
03
Output — The redacted .docx is rebuilt preserving all original formatting — bold, italic, tables, headers, and footers are all intact.
